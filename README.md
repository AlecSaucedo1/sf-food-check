# SF Food Check

Mobile-first San Francisco restaurant health inspection browser. This repository contains the production-ready MVP, including DataSF ingestion, inspection history, violations, inspector-comment enrichment, a PWA frontend, health checks, and Render deployment configuration.

The app clearly separates official SFDPH outcomes and inspector narrative from consumer-friendly interpretation. It is an independent project and is not affiliated with or endorsed by the City and County of San Francisco.
